# SketchBit

SketchBit is a Data-Driven platform for Real-Time collaborative editing rendering, utilizing a highly optimized Engine and Processor architecture.

With SketchBit, you get a lightweight tool that stays out of your way.

**What you get**

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchBit.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
